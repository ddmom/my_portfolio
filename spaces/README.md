# 공간 배치

`cafe_previs.html`이 여는 공간 배치 파일을 모아 둔 폴더입니다. 툴은 하나이고, 공간마다 배치 파일만 따로 둡니다.

- 여는 주소: `cafe_previs.html?space=dalbit` (머리말의 "공간" 목록에서도 고를 수 있습니다)
- `index.json`: 목록에 보일 공간. `id`는 주소에 쓰는 이름, `file`은 이 폴더 안의 배치 파일
- `royal_banquet.json`: 궁중 연회장 (12×18m, 천장 7m, 30초 5샷 동선). 여는 주소는 `cafe_previs.html?space=banquet`. 마찬가지로 `builtinSpaces`에도 들어 있습니다.
- `bar_cafe.json`: 바 카운터 카페 (8×7m, 천장 3.2m, 16:9 · 30초 5샷 동선: 입구 진입 → 바로 걸어감 → 바리스타에게 다가감 → 뒤 커피머신 드러냄 → 커피머신 클로즈업). 아이소메트릭 카페 레퍼런스 이미지(컨셉 참고에 들어 있음)를 실제 치수로 옮긴 배치입니다. 여는 주소는 `cafe_previs.html?space=bar_cafe`. `builtinSpaces`에도 들어 있습니다.
- `romance_cafe.json`: 비 오는 밤 카페 (6×5m, 9:16 · 40초 8샷). 남주가 들어와 바 스툴에 앉아 주문 → 여주 바리스타가 머신으로 가서 그라인딩·탬핑 → 포터필터 장착·컵 놓기 → 에스프레소 추출(30~35.5초에 줄기가 흐름) → 남주를 보며 미소. 남주는 7초에 "걷는 남주"에서 "앉은 남주"로 바뀝니다(보이는 시간). 여는 주소는 `cafe_previs.html?space=romance_cafe`.
- `dalbit_pungryu.json`: 달빛풍류 주막 (5×7m, 30초 5샷 동선). 같은 내용이 `cafe_previs.html` 안(`builtinSpaces`)에도 들어 있어, 툴은 그쪽을 먼저 씁니다. 배치를 고치면 두 곳을 함께 바꿉니다.

## 새 공간 추가 (예: 화음스튜디오)

1. 툴에서 벽·가구·카메라를 배치하고 "프로젝트 저장"을 누릅니다.
2. 받은 JSON 파일을 이 폴더에 넣습니다. 파일 안 `space` 값(`id`, `title`, `prefix`, `place` 등)을 그 공간에 맞게 바꿉니다.
3. `index.json`에 한 줄을 추가합니다.

## 샷별 카메라 플로 이미지

오른쪽 "Flow 샷" 탭의 "샷별 카메라 플로 이미지 ZIP"을 누르면 샷 하나당 PNG 한 장이 나옵니다(5샷이면 5장). 한 장에는 시작 → 끝 화면, 카메라 무빙, 피사체·액션, 위에서 본 동선이 들어갑니다.

## 인물 걷기 (시간별 위치 키)

인물 더미 목록의 "⏱ 이 시간 위치 기록"을 누르면 재생 위치(현재 시간)에 지금 위치·방향이 기록됩니다. 시간을 옮겨 인물을 "이동"한 뒤 한 번 더 기록하면 그 사이를 걸어갑니다. 키가 2개 이상인 인물은 이동·방향을 바꿀 때 그 시간의 키가 자동으로 고쳐지고, 키프레임·영상에도 움직인 위치로 찍힙니다. 움직이는 인물은 카메라 충돌 검사에서 빠집니다.
