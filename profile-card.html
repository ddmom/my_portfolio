Figma로 보내기

이 카드의 글과 사진을 Figma 플러그인 Profile Card Maker로 옮겨요. Figma에서는 글자와 사진을 고칠 수 있는 카드로 만들어져요.

  • 1단계 · 카드 내용 복사하기

    복사가 안 되면 파일로 저장해서 플러그인에서 그 파일을 선택하면 돼요.
    다른 사람에게 카드를 보내는 경우: 「파일로 저장 (.json)」을 누르고, 저장된 파일을 카카오톡이나 메일로 보내 주세요.

  • 2단계 · Figma에서 붙여넣기

    Figma 데스크톱 앱 → Plugins → Development → Profile Card Maker 실행
    → 웹페이지에서 가져오기 탭 → 입력칸을 누르고 Ctrl+V(맥은 ⌘+V), 또는 저장한 파일 선택
    → Figma에 카드 만들기

카드 이미지가 완성됐어요

  • 파일로 저장하기

    누르면 profile-card.png 파일로 저장돼요. 확인 창이 뜨면 저장을 눌러 주세요.

  • 파란 테두리 안의 카드 이미지를 직접 저장하기

    PC: 카드 이미지 위에서 마우스 오른쪽 버튼 → 이미지를 다른 이름으로 저장
    휴대폰: 카드 이미지를 손가락으로 길게 누르기 → 이미지 저장 (사진 앱에 저장돼요)

  • 복사해서 바로 붙여넣기

    복사한 이미지는 파일로 저장되지 않아요. 카카오톡 대화창, PPT, 메일 쓰기 화면 등에서 Ctrl+V(맥은 ⌘+V)를 누르면 붙여넣어져요.
